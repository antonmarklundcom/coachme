## If it goes wrong

| Symptom | Cause | Fix |
|---|---|---|
| Schema command hangs or times out | you ran it over Hostinger SSH (IPv6 to Neon) | run it from your own machine |
| `extension "…" is not available` | extension not enabled on the Neon branch | run `CREATE EXTENSION IF NOT EXISTS …` in Neon's SQL editor, then migrate again |
| Live site: generic "Application error" / `Digest:` | stale or malformed `DATABASE_URL` in hPanel | fix the value, then **redeploy** |
| `ERR_INVALID_URL`, error `input` contains `DATABASE_URL=` | key pasted into the value field | paste the raw value only |
| Auth redirects to the wrong host | `NEXTAUTH_URL` / `AUTH_URL` still on the old URL | update it and redeploy |
